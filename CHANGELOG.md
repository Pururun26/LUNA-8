# Changelog

## [1.0.0] - 22-11-2026
### Added
- 160x120 framebuffer with 16-color palette.
- UTF-8 Monogram font with Cyrillic support.
- Native tilemap system in C (`mapdata`, `map`, `tile`).
- Multi-color transparency (colorkey masks and tables).
- Sandboxed Lua 5.4 environment with `utf8` library.
- WebAssembly and Native builds.
- Dual build system (GUI for release, Console for development).
